# 世界の株価・底練りブレイクアウト分析アプリ

日本株・米国株・海外株・ETFを対象に、株価チャート、期間内の最高値・最安値、そして「大調整後の底練りブレイクアウト」を確認するためのPythonアプリです。

外部ライブラリは使っていません。Python標準ライブラリだけで動きます。

## 起動方法

Anaconda Promptを開き、次の順番で実行してください。

```bat
conda activate base
cd /d C:\Users\saban\Documents\Codex\2026-06-23\python-csv
python app.py
```

ブラウザが自動で開きます。終了するときは、画面右下の「アプリを終了」を押してください。

テストを実行する場合は次のコマンドです。

```bat
python -m unittest -v
```

## 主な機能

- 株価チャート表示
- 期間内の最高値・最安値・騰落率表示
- 株式 / ETF の区分選択
- 判定モード切替
  - 汎用：大調整後
  - 上場後特化
- 手動の日付範囲を指定した底練り評価
- 大調整後の底練り・ボラティリティ収縮・出来高付きブレイクアウト判定
- 急騰後のピーク警戒ゾーン表示
- チャート上のカーソル位置の値表示
- 底打ち候補日を選択し、その後の最安値と比較する評価表示
- 銘柄名・銘柄コードの簡易検索
- 過去シグナルの5日後・20日後・60日後の簡易バックテスト集計
- 複数銘柄の一括分析
- SQLiteによる日足データと分析結果の保存
- 保存済みデータへの差分追加更新

## 現在の底練り・底打ち候補判定

ゴールデンクロスは使いません。移動平均線の交差は横ばい局面でダマシが多いため、価格そのものの動きと出来高を重視します。

画面の「底練りの分析範囲」が空欄の場合は、これまでどおり取得できる全履歴を使って通常判定します。開始日・終了日を入力した場合は、その範囲内の日足だけに切り出して底練り状態を再判定します。過去の大型調整局面だけを見たいときに使ってください。

判定モードは2種類あります。

- **汎用：大調整後**  
  任天堂やサンリオのように、歴史のある銘柄の中期的な大調整後を見るためのモードです。

- **上場後特化**  
  キオクシアやIPO後の暴騰・暴落型銘柄を見るためのモードです。上場後1年の高値から大きく下がった後の底練りを重視します。

### 1. 大調整フィルター

過去500営業日の高値から十分に下落しているかを見ます。

- 株式: 高値から40%以上下落
- ETF: 高値から25%以上下落
- 高値を付けた日から一定期間が経過していることも確認

### 2. 底練り・ボラティリティ収縮

売り圧力が弱まり、値動きが落ち着いているかを見ます。

- 直近60営業日の終値レンジが狭いこと
- 直近20営業日の平均絶対騰落率が2.5%以下であること
- 条件が一日だけでなく、一定期間まとまって成立していること

### 3. 最終トリガー

底練り後に本当に上へ抜けたかを確認します。

- 60日レンジを上抜け
- または、20日高値を更新しながら大きく上昇
- 出来高が20日平均より増えていること
- 終値が日中レンジの上側で終わっていること
- その後2営業日、ブレイク水準を大きく割らずに維持すること

## チャートの色

- **緑色の帯**  
  底練り候補です。大きく売られた後に、値動きが落ち着き、レンジ内で固まりつつある状態を示します。

- **薄い黄色の帯**  
  過熱ゾーンです。急騰後に高値圏へ入り、上昇がかなり進んでいる状態を示します。

- **濃い黄色の帯 / 赤い縦線**  
  ピーク強警戒ゾーンです。過熱に加えて、短期失速や移動平均線の鈍化などが重なった場所を示します。天井を断定するものではなく、「ここから上値追いは慎重に見るべき場所」を示す補助表示です。

## 底打ち候補の評価

底打ち候補が複数ある場合は、画面の「底打ち候補を選択」から日付を選べます。候補日の株価と、その後の最安値を比較し、候補日が早すぎなかったかを確認できます。

## 一括分析でETFを指定する方法

通常の株式はそのままコードを書きます。ETFは `|ETF` を付けます。

```text
7203
6758
AAPL
VOO|ETF
QQQ|ETF
```

## 保存データについて

取得した日足と分析結果は `stock_cache.db` に保存されます。

- 同じ銘柄を再分析するときは、保存済みデータを使います
- 「最新データを追加」で不足分だけ取得します
- 「全結果を再計算」で、保存済み日足を使って現在のアルゴリズムで再判定します

## 注意

このアプリは研究・検証用です。底打ち候補の検出は投資成果を保証するものではありません。実際に投資判断をする場合は、業績、開示情報、出来高の質、地合い、リスク許容度も必ず確認してください。
